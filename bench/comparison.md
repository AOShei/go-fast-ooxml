# Comparison with the tools in use today

Generated by `bench/compare.py`; do not edit. Numbers are from one machine and compare tools on that machine only.

Machine: AMD Ryzen 9 9900X 12-Core Processor, 24 logical cores, Linux-6.18.60-1-lts-x86_64-with-glibc2.44, Python 3.13.18, go1.27.3-X:nodwarf5.

Versions: docx2txt 0.9, markitdown 0.1.9, openpyxl 3.1.5, python-docx 1.2.0, python-pptx 1.0.2.

Each file is read once in a process of its own. For the Python tools the time does not count importing the library (0.01 to 0.4 s, in `baseline.md`). For this library it is the whole run of the command `gofastooxml -format text`, from start to exit, the best of three. Peak memory is the peak resident size of the process.
